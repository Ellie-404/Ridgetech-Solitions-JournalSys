Sette opp en type prøveform, som lærerene kan rette.
Legge inn prøver som skal kunne velges av sektretær når de oppretter time for pasient.
 
Hvem er de faktiske brukerne (elever, lærere, begge), og hvor mange samtidig?
Lege, sektretær og admin
Legene skal være fiktive
Legene og sektretærer skal ha lik tilgang.
 
Timebestilling: kan pasienten velge lege selv, eller bare tid? Kan timer avbestilles eller flyttes?
Pasient ringer, og sekretær bestemmer time.
 
De spør om å kunne redigere time som allerede er avtalt.
De har ønske om historikk (når legetime blir lagt til, hva den handlet om og når det skjer).
Når en pasient opprettes, så lages tilfeldig fødselsdato, personnummer, navn, etternavn, og adresse.
Sekretær skal kunne hente pasient og lage ny pasient.
Kunne markere timer som grønn, gul, rød eller blå.
 
Bonus: Kunne opprette faktura og regnskap.
